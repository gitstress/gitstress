# Security Policy

## Supported Versions

We actively support and release security patches for the following versions:

| Version | Supported |
| ------- | --------- |
| 0.11.x  | Yes       |
| < 0.11  | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within GitStress, please send an email to security@gitstress.com. All security vulnerabilities will be promptly addressed.

Please include:
- A description of the issue and potential impact
- Detailed steps to reproduce the issue (code samples, test cases, or CLI reproduction commands)
- Any proposed mitigations or fixes

We aim to acknowledge receipt of security reports within 48 hours and provide updates until the vulnerability is resolved and patched.
